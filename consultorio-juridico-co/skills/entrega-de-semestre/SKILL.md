# Entrega de semestre

> **La entrega de semestre es el momento de mayor riesgo del consultorio.** Es cuando se
> pierden los términos, se olvidan las promesas hechas al usuario y se rompe la
> continuidad de la representación.

**Antes de empezar.** Leer el perfil: protocolo de entrega y docentes responsables.

## Por qué falla la entrega

| Falla | Consecuencia |
|---|---|
| El expediente está en la cabeza del estudiante, no en el archivo | El que recibe reconstruye desde cero, o no reconstruye |
| Los términos no están registrados | Se pierden |
| Lo que se le prometió al usuario no está escrito | El nuevo estudiante promete otra cosa |
| No hay contacto actualizado del usuario | El caso muere por incomunicación |
| El nuevo estudiante recibe veinte casos en una tarde | No alcanza a leer ninguno |
| Nadie verifica que la entrega se hizo | Casos que quedan sin dueño |

**La entrega se prepara durante todo el semestre**, no la última semana. Un expediente que
se lleva bien se entrega solo.

## El expediente que se puede entregar

Cada caso, al cierre, debe tener:

| # | Elemento | Verificación |
|---|---|---|
| 1 | **Ficha de consulta** completa y actualizada | |
| 2 | **Datos de contacto del usuario verificados** | Llamar y confirmar antes de entregar |
| 3 | **Cronología** de lo actuado, con fechas | |
| 4 | **Términos** vivos, con norma y vencimiento | |
| 5 | **Documentos** del usuario, digitalizados e indexados | |
| 6 | **Piezas radicadas**, con constancia de radicación | |
| 7 | **Estado procesal** actual, con radicado y despacho | |
| 8 | **Lo que se le prometió al usuario**, textual | |
| 9 | **Lo que está pendiente**, con fecha | |
| 10 | **Autorización de tratamiento de datos** | |
| 11 | **Poder** vigente y su alcance | |

## La nota de traspaso

Es el documento que el nuevo estudiante lee primero. Debe permitirle actuar sin llamar a
nadie.

```markdown
## Nota de traspaso — Caso [n.º]

### En cinco líneas
[Quién es el usuario, qué le pasó, qué estamos haciendo, en qué va, qué sigue]

### 🔴 Lo primero que hay que hacer
1. [Acción] — antes del [fecha]
[Si no hay nada urgente, decirlo: «No hay acciones urgentes. La próxima actuación es el
(fecha)»]

### El usuario
| Dato | Contenido |
|---|---|
| Nombre y contacto verificado el | [fecha] |
| Cómo prefiere que lo contacten | |
| Qué entiende de su caso | |
| **Qué se le prometió, textualmente** | |
| Situación particular a tener en cuenta | [dificultad de desplazamiento, situación de salud, riesgo, etc.] |

### El caso
| Dato | Contenido |
|---|---|
| Área y problema jurídico | |
| Vía elegida y por qué | |
| Radicado y despacho | |
| Contraparte y su apoderado | |
| Etapa procesal | |
| Docente responsable | |

### 🔴 Términos vivos
| Actuación | Vence | Norma | Estado |
|---|---|---|---|

### Cronología
| Fecha | Actuación | Resultado |
|---|---|---|

### Lo que está pendiente
| Pendiente | Quién | Para cuándo |
|---|---|---|

### Lo que intenté y no funcionó
[**La sección más valiosa y la que nunca se escribe.** Evita que el siguiente repita el
camino: «Se intentó notificar en la dirección X y la contraparte ya no vive ahí»;
«se pidió conciliación y no asistieron»]

### Dudas abiertas
| Duda | Estado |
|---|---|

### Archivos
[Ruta o ubicación física de cada documento]

---
**Entregado por:** [ ] · **Recibido por:** [ ] · **Fecha:** [ ]
**Docente que verifica la entrega:** [ ]
```

## El protocolo de entrega

```
SEMANA -4  Inventario de casos por estudiante. Identificar los que quedan abiertos.
SEMANA -3  Poner al día expedientes: digitalizar, indexar, registrar términos.
           Verificar datos de contacto de cada usuario, llamando.
SEMANA -2  Redactar notas de traspaso. Revisión del docente.
SEMANA -1  **Reunión de entrega, caso por caso**, entre estudiante que sale y estudiante
           que entra, con el docente presente.
           Firmar acta de entrega.
SEMANA 0   El nuevo estudiante **contacta a cada usuario** para presentarse.
SEMANA +1  Verificación de dirección: ¿todos los casos tienen responsable?
           ¿Todos los usuarios fueron contactados?
```

**La reunión caso por caso no es reemplazable por un documento.** Veinte minutos de
conversación transmiten lo que el expediente no dice: el tono del usuario, las
dificultades, lo que el docente ya opinó.

**El contacto del nuevo estudiante con el usuario es obligatorio.** Un usuario que no sabe
quién lleva su caso deja de confiar en el consultorio, y con razón.

## Casos que no se deben entregar sin más

| Situación | Qué hacer |
|---|---|
| **Término venciendo en las próximas dos semanas** | Lo resuelve quien sale, o se asigna con prioridad y seguimiento del docente |
| **Audiencia programada en el período de transición** | Definir quién asiste, con nombre |
| **Usuario en situación de riesgo** | Entrega personal, con el docente presente |
| **Caso fuera de la competencia del consultorio** | Cerrarlo y orientar al usuario, no traspasarlo |
| **Caso sin actuación en más de seis meses** | Evaluar cierre o reactivación antes de entregar |
| **Usuario ilocalizable** | Documentar las gestiones y definir el cierre conforme al reglamento |

## Al cerrar un caso

Cuando el caso termina en lugar de traspasarse:

| # | Paso |
|---|---|
| 1 | **Informar al usuario** el resultado y qué significa |
| 2 | **Entregarle copia** de lo actuado |
| 3 | **Explicarle si tiene algo pendiente** (cobrar, cumplir, recursos) |
| 4 | **Advertirle sobre términos futuros** si los hay |
| 5 | Acta de cierre firmada |
| 6 | Archivo del expediente conforme al reglamento y a la política de datos |

## Salida

```markdown
[NOTAS DE TRABAJO — CONSULTORIO JURÍDICO]

## Entrega de semestre — [estudiante] — [período]

### Inventario
| Caso | Usuario | Área | Estado | Términos vivos | Se entrega / se cierra | Recibe |
|---|---|---|---|---|---|---|

### 🔴 Casos que requieren atención antes de la entrega
| Caso | Situación | Acción | Responsable | Fecha |
|---|---|---|---|---|

### Notas de traspaso
[Una por caso]

### Verificación de la entrega
| # | Verificación | Estado |
|---|---|---|
| 1 | Todos los expedientes al día | |
| 2 | Todos los términos registrados con norma | |
| 3 | Contacto de todos los usuarios verificado | |
| 4 | Notas de traspaso revisadas por el docente | |
| 5 | Reunión de entrega caso por caso realizada | |
| 6 | Acta de entrega firmada | |
| 7 | Usuarios informados del cambio de estudiante | |
| 8 | Casos cerrados con acta y con usuario informado | |

### Casos sin responsable asignado
[🔴 Sección propia. No puede quedar ninguno]

### Aprendizajes del período
[Qué falló y qué mejoraría la próxima entrega — para el docente y para el consultorio]
```

## Compuertas

- **Ningún caso queda sin responsable.** Es la verificación final y no admite excepciones.
- **Todo usuario debe ser informado del cambio de estudiante.**
- **Los casos con términos próximos no se entregan sin plan concreto.**
- **La reunión de entrega caso por caso es obligatoria.**
- **Los datos de contacto se verifican llamando**, no leyendo la ficha.

## Lo que esta skill NO hace

- No cierra casos por su cuenta: propone el cierre conforme al reglamento.
- No contacta a los usuarios.
- No sustituye el acta de entrega ni la supervisión docente.
